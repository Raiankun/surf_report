    はじめての人へ 用語・乗り方・パドリング・横に滑る・上達のコツ・安全とマナー

    サイドショア
    海岸と平行に吹く風。弱ければ問題ないが、強いと流されやすい。
    グラッシー
    ほぼ無風で、海面がガラスのようにツルツルの状態。朝に多い。
    うねり（スウェル）
    遠くの低気圧や台風で生まれ、長い距離を旅してきた波。まとまりがあり、サーフィン向き。
    風波（かぜなみ）
    近くで吹いている風が作る波。周期が短く、崩れ方がまばら。
    周期（ピリオド）
    波と波の間隔（秒）。10秒以上だと力強いうねり、7秒以下は風波が中心。
    波高（有義波高）
    予報で使う波の高さ。大きい方から3分の1の波の平均で、ときどきこれより大きい波も来る。
    ひざ・腰・胸・頭
    波の大きさを、人の体のどこまであるかで表す言い方。頭を超えると「頭オーバー」、2倍で「ダブル」。
    セット
    数本まとまってやってくる大きめの波。セットの合間は静かになる。
    ブレイク
    波が崩れること、または崩れる場所。
    ピーク
    波がいちばん最初に崩れ始める場所。ここに近い人が優先して乗れる。
    ショルダー
    ピークの横の、まだ崩れていない斜面の部分。ここを横に滑っていく。
    ダンパー（クローズアウト）
    横一直線に一気に崩れる波。横に滑れないので乗りにくい。
    スープ
    崩れたあとの白く泡立った波。初心者のテイクオフ練習にちょうどいい。
    インサイド／アウト
    岸に近い浅い場所がインサイド、波が崩れ始める沖側がアウト。
    ゲッティングアウト
    崩れる波を越えて、沖の波待ちの場所まで出ていくこと。
    パドリング
    ボードに腹ばいになり、両腕で水をかいて進むこと。
    テイクオフ
    波に押されてボードが走り出した瞬間に立ち上がること。
    ドルフィンスルー
    ボードごと水中に潜って波をくぐり抜ける技。主にショートボードで使う。
    リーシュコード
    ボードと足首をつなぐコード。ボードを流さないための必需品。
    前乗り（ドロップイン）
    ピーク寄りの人がすでに乗っている波に、横から割り込むこと。いちばん嫌われるマナー違反。
    離岸流（カレント）
    岸から沖へ向かう強い流れ。波が割れていない、濁っている所に多い。
    大潮・小潮
    月の満ち欠けで変わる潮の動きの大きさ。大潮は満潮と干潮の差が大きく、流れも強くなりやすい。
    上げ潮・下げ潮
    満潮に向かうのが上げ潮、干潮に向かうのが下げ潮。上げ始めは波が良くなることが多いと言われる。
    ソフトボード／ロングボード
    ソフトボードは表面が柔らかく安全。ロングボードは浮力があり波に乗りやすい。初心者はこのどちらかから。

    はじめはサーフスクールに入るのがいちばんの近道です。ボードは浮力の大きいソフトボードかロングボードを選びましょう。

    1. 海に入る前に波・風・潮をこのページでチェック。準備運動をして、リーシュコードを後ろ足の足首に付けます。しばらく浜から波の崩れ方とほかの人の動きを観察しましょう。
    2. パドリングボードの真ん中に腹ばいになり、つま先がボードの後ろの端に来る位置に。あごを少し上げ、腕を大きく交互に回して水をかきます。
    3. ゲッティングアウト白波が来たら、ボードを押して胸を浮かせ、体と板の間に波を通します（プッシュスルー）。波の小さい所や、波が割れていない場所を選んで沖へ。
    4. 波を待つボードにまたがって沖を見ます。セットの間隔を数え、ピークのど真ん中ではなく、少し外れた場所で待つのが初心者の基本です。
    5. 波をつかまえるうねりが近づいたら岸の方へ向き、全力でパドル。ボードがぐっと押される感覚が来てから、さらに2〜3かきします。
    6. テイクオフ両手を胸の横について上体を起こし、一気に足を引き込みます。前足は両手の間、目線は進む方向、ひざを曲げて低く構えます。
    7. 波から降りる・戻る波が終わったら、ボードを前に飛ばさないよう後ろ側へ降ります。戻るときは、波に乗っている人の進路を横切らないようにパドルで回り込みます。

    最初はインサイドのスープで、「パドル→立つ」を何度も練習するのがおすすめ。立てるようになってから沖の波に挑戦しましょう。

    波に乗れるかどうかは、立つ前のパドリングで8割決まると言われます。正しい姿勢、いい位置、早めのスタートの3つを押さえましょう。

    1. 寝る位置を決める

    • ボードのノーズ（先端）が水面から2〜3cm浮く位置が正解。
    • ノーズが沈んで水をかぶる → 体を少し後ろへ。
    • ノーズが高く上がって進まない → 体を少し前へ。
    • 板の中心線に、鼻・おへそ・両足をそろえるとまっすぐ進む。

    2. 腕のかき方

    • 指を軽く閉じて、手のひらで水をつかむ感じ。
    • 肩から大きく前に伸ばし、胸の下まで深くかく。
    • 左右交互に、同じリズムで。水面をバシャバシャたたかない。
    • 胸を軽く反らせると、腕が回しやすく前も見やすい。

    3. 待つ位置とタイミング

    • 波が崩れ始めるピークの少し横（ショルダー側）で待つ。
    • セットの1本目は見送って、どこで崩れるかを確認するのも手。
    • 波が5〜6m後ろまで来たら、岸の方を向いて漕ぎ始める。
    • 振り返って波を確認しながら、だんだんスピードを上げる。

    4. 乗れる瞬間

    • お尻（テール）が持ち上がり、ボードが前に傾く感覚が来る。
    • そこで止めずにさらに2〜3かき強く漕ぐ。これが一番大事。
    • ボードが自分で滑り出したら、テイクオフ（立ち上がる）。

    うまくいかないときは

    波に置いていかれる
    漕ぎ始めが遅いか、最後の2〜3かきで止めている。もっと早く、最後まで漕ぐ。
    ノーズが刺さって前に転ぶ（パーリング）
    位置が前すぎるか、波が掘れすぎている。体を少し後ろにずらし、斜めに漕ぎ出す。
    立ったら波が抜けていく
    立つのが早すぎる。ボードが滑り出すまで漕ぎ続ける。
    まっすぐ進まない
    体が板の中心からずれている。足をそろえ、左右の腕を同じ強さでかく。

    立てるようになったら、次は崩れていない斜面（ショルダー）を横に走る練習です。まっすぐ岸へ向かうだけより、ずっと長く乗れます。

    波の向きを知る

    • 沖から岸を向いて、右へ崩れていく波がライト、左がレフト。
    • 波待ち中に、どちらへ崩れていくかを見ておく。
    • 左足が前（レギュラー）の人はライトで波に顔を向けて乗れるので、はじめはこちらが簡単。右足が前（グーフィー）の人はレフト。

    斜めにテイクオフ

    • 真岸に向けず、行きたい方向へ10〜30°ほど板を向けて漕ぐ。
    • 立った瞬間から、もう横へ走り出せる。
    • 最初はスープで、立ってから斜めに進む練習から。

    曲がるコツ

    • 目線 → 肩 → 腰 → 足の順に、行きたい方向へ向ける。体は見た方へ進む。
    • 波に顔を向けている時はつま先側、背中を向けている時はかかと側に体重をのせる。
    • ひざを曲げて低く。棒立ちだとすぐ倒れる。

    スピードを保つ（トリム）

    • 斜面の真ん中あたりをキープして走る。
    • 遅くなって波に置いていかれそう → 前足に体重、少し下へ。
    • 速すぎて前に出すぎる → 後ろ足に体重、斜面の上へ戻る。
    • 慣れたら、斜面を上下にゆるく動いて加速する。
    1. スープでまっすぐ立つ崩れた白波で、パドル→立つを安定してできるまで繰り返す。
    2. スープで体重移動立ったあと、目線と体重で左右に進む向きを変えてみる。
    3. うねりで斜めにテイクオフ崩れる前の波を、ピークの少し横から斜めに漕いでつかまえる。
    4. 斜面を横に走るショルダーの真ん中をキープして、できるだけ長く横へ。

    波が前で崩れて行き止まりになったら、板を体から離さずに波の後ろ側へ降りるか、板を上に向けて波の裏へ抜けます（プルアウト）。前に飛び込むと、板が後ろから飛んできて危険です。

    プロの解説動画や上達記事でくり返し言われている、初心者がつまずきやすいポイントを、段階ごとにまとめました。それぞれ、詳しく見られる動画も付けています。

    1波をつかまえる

    • ボードが水平になる位置に寝る。前に乗りすぎるとテールが浮いてノーズが刺さり、後ろすぎると波に押してもらえない。
    • 波の速さに「合わせる」。リレーでバトンを受け取るように、波が来る少し前から漕ぎ始めて、波が追いつく瞬間にいちばん速くなっているのが理想。
    • 押された感覚のあと、さらに2〜3かき。ここで止めると波だけが先に行ってしまう。
    • 早すぎると刺さり（パーリング）、遅すぎると乗り遅れる。タイミングのズレは、待つ位置を少しずらして調整する。
    ▶ 正しいパドリングの方法（Surfing TV）▶ 波キャッチの教科書（ヒガシーサー）

    2立ち上がる（テイクオフ）

    • あごと胸を上げて、進む方向を見る。足元やボードを見ると体が沈み、バランスを崩しやすい。
    • 手は胸の横につき、一気に立つ。ひざをついてから立つクセがつくと、うねりでは間に合わなくなる。
    • 前足は両手のあいだに。立った直後に転ぶときは、足の位置と目線をまず確認。
    • 立ったら、ひざを曲げて低く。棒立ちは波の動きについていけない。
    ▶ テイクオフ 4つのコツ（河村カイサ）▶ テイクオフのポイント（90秒でわかる）

    3海に入る前と、スープでの練習

    • 入る前の5分の陸トレ。①ボードに寝た姿勢を確かめる、②胸を上げる動きを5回、③ゆっくりテイクオフを3回。体に動きを思い出させてから海へ。
    • まずはスープ（崩れた白波）で。「漕ぐ→波と速さを合わせる→立つ→岸まで滑る」を何本もくり返すと、乗る感覚が早く身につく。
    • 家でもできる。床でのテイクオフ動作の練習は、1日数分でも効果がある。
    ▶ 1日4分のテイクオフトレーニング（森下波瑠）▶ スープで基礎練習（ドジ井坂）

    4横に走るへのステップ

    • 行きたい方向を先に見る。目線→肩→腰の順に向けると、ボードも自然にそちらへ進む。
    • 少し斜めに漕ぎ出す。真岸に向けず、崩れていく方向へ板を向けておくと、立った瞬間から横に走れる。
    • くわしい体重のかけ方は「横に滑る」タブへ。
    ▶ テイクオフの次に見る動画 横に走る方法（Surfing TV）▶ 初めてでも横に走れる？（大人のサーフィン理論）

    5上達を早める心がけ

    • 最初はスクールか、慣れた人と一緒に。1人で入らないことが一番の安全策。
    • 自分に合った浮力のボードを。浮力が足りないと、波をつかまえる段階でつまずく（「学ぶ」→「ボード」で計算できます）。
    • 小さめでメローな波の日を選ぶ。このサイトの一覧で、初心者向けの「◎」やメロー・ファンウェイブのポイントを探すのが近道。

    参考：プロサーファー・コーチの解説動画（各リンク先）、pocketsurf「テイクオフのコツ」、rere「サーフィン初心者のテイクオフ」。内容は要点を自分の言葉でまとめ直しています。

    マナー

    • 前乗りしない。ピークに近い人が優先。乗る前に左右を確認。
    • 1本の波に1人。乗っている人がいる波には乗らない。
    • ボードを手放さない。流れたボードは周りの人に当たると大ケガのもと。
    • あいさつと順番。ローカルの人を尊重し、混んでいる場所に無理に入らない。
    • 駐車・ゴミ・着替えは地域のルールを守る。

    安全

    • 1人で入らない。仲間かスクールと一緒に。
    • 大きい日は入らない勇気を。「腰〜胸」を超える日や台風のうねりは初心者は見学。
    • 雷が鳴ったらすぐ上がる。海の上はとても危険。
    • 体が冷えたら早めに上がる。水温に合ったウェットスーツを。
    • 警報・注意報（高波・強風）が出ていたら入らない。

    離岸流に流されたら

    • あわてず、ボードにつかまる。ボードは浮き輪になる。
    • 岸と平行に移動して流れから出る。岸に向かってまっすぐ戻ろうとしない。
    • 出られないときは手を大きく振って助けを呼ぶ。
    • 緊急時は 118（海上保安庁）へ。
